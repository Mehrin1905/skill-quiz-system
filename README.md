# Skill Quiz System 🎯

## 📌 Description
A web-based quiz application that evaluates user performance and determines eligibility for contests and hackathons.

## 🚀 Features
- Multiple-choice quiz
- Instant feedback (correct/wrong answers)
- Score calculation
- Contest qualification system
- Ranking & hackathon eligibility

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
